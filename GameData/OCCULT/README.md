## Description

A compendium of optional ModuleManager patches for Kerbal Space Program, covering balance tweaks, cross-mod integration and quality of life fixes.

Every patch ships disabled and is toggled individually from the PatchManager in-game menu, so you take only the changes you want and nothing else is touched. Each one declares the mods it depends on, so PatchManager only offers you the patches your install can actually use.

* **Balance** - robotics torque, SystemHeat fission engine response, fueled stock and AirplanePlus wings, lighter Mk2 and Mk2 Expansion parts, and more LqdHydrogen to collect from Jool with SpaceDust.
* **Features** - JX2 antenna feeds for Near Future Launch Vehicles, and Rational Resources fuel switching and structural options for Mk3 Expansion, Near Future Aeronautics and stock parts.
* **VAB Organizer** - categories for Mk3 Expansion, KW Rocketry, AirplanePlus and OPT Spaceplane.
* **Misc** - a faint Jool glow on Laythe with Scatterer, tidier AJE part titles, and Extraplanetary Launchpads without its stock parts.

## Installation

To install, place the GameData folder inside your Kerbal Space Program folder, and install the dependencies below. If asked to overwrite files, please do so.

**REMOVE ANY OLD VERSIONS BEFORE INSTALLING**.

## Dependencies

* [ModuleManager](https://github.com/sarbian/ModuleManager)
* [PatchManager](https://github.com/linuxgurugamer/PatchManager)

Each patch also needs the mods it changes. PatchManager hides any patch whose mods aren't installed, so nothing else is required.
