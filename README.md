## Description

A compendium of optional ModuleManager patches for Kerbal Space Program, covering balance tweaks, cross-mod integration and quality of life fixes.
Every patch ships disabled and is toggled individually from the PatchManager in-game menu, so you take only the changes you want and nothing else is touched.
Patches are grouped into four categories: Balance, Features, VAB Organizer and Misc.
Each one declares the mods it depends on, so PatchManager only offers you the patches your install can actually use.
Coverage includes stock and Making History parts alongside AirplanePlus, AJE, Extraplanetary Launchpads, JX2 Antenna, KW Rocketry, Mk2/Mk3 Expansion, Near Future Aeronautics, Near Future Launch Vehicles, OPT Spaceplane, Rational Resources, Scatterer, SpaceDust, SystemHeat and VAB Organizer.

## Installation

To install, place the GameData folder inside your Kerbal Space Program folder. If asked to overwrite files, please do so.

**REMOVE ANY OLD VERSIONS BEFORE INSTALLING**.

## Dependencies

* Hard dependencies:
	* [ModuleManager](https://github.com/sarbian/ModuleManager)
	* [PatchManager](https://github.com/linuxgurugamer/PatchManager)
* Soft dependencies:
	* Individual patches require the mods they patch. PatchManager hides any patch whose dependencies are missing, so no other mod is mandatory.
